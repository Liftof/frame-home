# Changelog

## 0.8.0 — public experimental release

- Portable, fresh public source tree based on the working The Frame prototype.
- tvOS-inspired home, full app library, six configurable favorites and stable remote focus.
- Native app icon framing with no bundled proprietary logo pack.
- Original Coast day/night wallpapers, Ardoise and local image imports with metadata removal.
- Optional sunrise/sunset configuration; no default personal location or HDMI associations.
- Regional Samsung TV+ examples and provider shortcuts, with documented tuning limitations.
- Loopback browser preview, reproducible unsigned build, publication checks and automated tests.
- French developer-mode tutorial, signing/install steps, compatibility notes and rollback instructions.

The portable changes in this release have browser and automated coverage. Hardware validation of this exact public version remains pending. The earlier personal prototype was exercised on a The Frame LS03B (2022), Tizen 6.5, firmware 1720.
